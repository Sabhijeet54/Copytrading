# Changes — 15 Oct 2026 (client feedback round)

No database migration is needed. Restart the API and web after pulling these files.

## 1. Strategy per client (admin decides who gets what)
- A client now sees and copies **only the strategies assigned to him** (by admin or by the master). Unassigned strategies are hidden; following them is blocked by the API.
- Admin → **Users & licences** → layers icon (**Strategies**) on a client row: assign / edit / remove each strategy with its own allocation.
- After **Add user** for a client, the Strategies dialog opens automatically.
- Master → **Strategies** → select a strategy → **Assign client** (by email) still works; **Remove** takes the strategy away from the client (history is kept).
- Existing subscriptions keep working. A removed client is marked with `stoppedReason = "Removed from strategy"` (re-assigning gives it back).

## 2. Lot multiplier
- Allocation option **Lot multiplier (× master lots)**: 1 = same lots as master, 2 = double, 0.5 = half (rounded down to whole lots, max 10×). Stored as `CAPITAL_PERCENTAGE` (× 100), so the copy engine is unchanged.
- Available in the admin Strategies dialog, the master Assign-client dialog and the client's own Settings dialog. Fixed lots / fixed qty / capital-based remain.
- Trade history: the old “PNL multiplier” is now **Lot multiplier ×** and scales both quantity and P&L (display + Excel export).

## 3. Licence
- **Add user**: licence dropdown — **2 Days (default)**, 30 Days, Admin key (365 days), custom, or none.
- **Assign licence** dialog uses the same dropdown.
- Users table now matches the requested layout: Name, Mobile, Licence, User type, Registration date, Licence assigned, Licence expiry, Strategies, Status (Active / Inactive dropdown), Actions.

## 4. Admin trade history
- Menu **Signals** → **Trade history**: all strategies, any date range, live LTP for open trades.
- New **Edit** (entry / exit / qty — P&L recalculated) and **Delete** (closed trades only; soft delete, `signalStatus = 'DELETED'`) on every row. Client orders are never changed.
- New **Strategy performance** table: trades, win rate, best, worst, total P&L per strategy for the filtered period.

## 5. Master: full client view
- New **Clients** page (`/master/clients`): every client of your strategies with broker (paper/live), strategies + multiplier, licence, trades today and today's P&L.
- New client detail page (`/master/client?id=…`): profile, licence, broker, strategies with today's P&L, live account (Positions / Holdings / Orders tabs with Exit) and copied-trade history (today / 7d / 30d / all).

## 6. Client: positions vs holdings, same-day history
- Separate pages: **Positions** (today only — open + closed-today with realized P&L, like Zerodha), **Holdings** (demat holdings from earlier days), **Today's orders**.
- Copied trades and closed paper positions are shown for **today only** (IST trading day) — the list starts empty every morning. Data is kept in the database for admin / master history.
- Positions page shows the same Today's P&L as the dashboard.

## 7. Paper / Live switch (client dashboard)
- The toggle now works: Paper = simulated, Live = real broker orders (asks for confirmation).
- If the server runs with `PAPER_MODE=true` (the default in `.env.example`) live trading is locked for everyone — set `PAPER_MODE=false` in `.env` to allow live trading.
- A daily broker re-login no longer resets the account to live.

## 8. Simpler navigation
- Every sidebar item opens its own page (no more scrolling up/down inside one long page).
- Master: Dashboard, Strategies, Place trade, Live trades, Open positions, Clients, Broker accounts.
- Client: Dashboard, My strategies, Positions, Holdings, Today's orders, Broker API, Broker connection.
- New `/broker` page for broker login; dashboards are short summaries.
